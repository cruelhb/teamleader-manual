## 하스피에 결근으로 떠도 바로 결근이 아닙니다

아래 두 경우 모두 하스피에는 **결근으로 표시**되지만, 이는 **임시 결근 상태**입니다.

- 연차가 아닌 상태로 출근하지 않은 경우
- 실제로 출근했으나 **캡스 출근 버튼을 누르지 않은** 경우

> <i class="ico ico--info"></i> **임시 결근 상태에서는 급여가 차감되지 않습니다.** 다만 그대로 두면 안 되고, 아래 경우에 맞게 처리해야 합니다.

## 경우 1 — 실제로 결근한 경우 (무급휴가 외)

**결근 다음 날 회사에 출근하는 즉시** 하스피에서 상신합니다.

<ol class="steps">
<li><span class="step__what">하스피 → 휴가/출장 상신 화면 열기</span></li>
<li><span class="step__what">종류에서 <b>결근</b> 선택 후 상신</span></li>
</ol>

![하스피 휴가 신청 화면에서 종류 목록을 펼쳐 결근을 선택한 모습](/img/결근-상신-선택.png)

## 경우 2 — 실제로 출근했으나 결근으로 표시된 경우

캡스 출근 버튼 미터치 등으로 결근으로 찍힌 경우입니다. **정상 출근 반영 요청 기안서**를 작성해 근태 수정을 요청합니다.

> <i class="ico ico--alert"></i> **증빙 첨부가 필수입니다.** 캡스 출입기록 또는 업무 화면으로 **9시 이전에 출근한 사실**을 증명해야 합니다.

### 결재라인

기안서는 아래 순서로 결재가 올라갑니다. **네 단계를 모두 거쳐야 근태가 수정됩니다.**

<ol class="steps">
<li><span class="step__what">기안</span><span class="step__who">해당 부서 팀장</span></li>
<li><span class="step__what">서면지원팀장 결재</span><span class="step__who">최종현 부장</span></li>
<li><span class="step__what">서면지원부장 결재</span><span class="step__who">나한빛 부장</span></li>
<li><span class="step__what">본부장 결재</span><span class="step__who">유명열 전무</span></li>
</ol>

### 기안서 작성 예시

![정상 출근에 따른 근태 관련 확인 건 기안서 예시. 결재란에 최종현 부장, 나한빛 부장, 유명열 전무가 순서대로 표시되어 있다](/img/정상출근-기안서-예시.png)

기안서에는 아래 네 가지를 씁니다.

| 항목 | 쓸 내용 |
| --- | --- |
| 1. 요청 배경 | 언제 정상 출근했는데 출근 버튼을 누락해 하스피상 결근으로 찍혔는지 |
| 2. 사실 관계 | 대상자, 캡스 출입 조회로 확인한 최초 출입 시각 |
| 3. 기타 사항 | 재발 방지를 위해 확인하겠다는 내용 |
| 4. 시행일자 | 기안 승인 시 정상 출근으로 변경 적용 요청 |
